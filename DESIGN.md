# Visual system

The brief pins a restrained historical identity. Use an exhibition programme: monumental Roman-inspired lettering, real group photography, stone surfaces, oxblood panels, and a calendar expressed as readable rows. This serves families checking dates on a phone in daylight as well as members reading at home.

Candidate systems considered: museum exhibition, heritage visitor guide, living-history programme (selected), archaeological field journal, theatre programme, walking-trail wayfinding, photographic society annual. Seed assigned direction 3. Catalog alternatives (shoebox archive, raku, teletext, early desktop, console, record sleeve) undermine either the brief's historical identification or straightforward event browsing; the brief's pinned direction takes precedence. User explicitly delegates design choices and requests no clarification loop.

Use locally hosted Cinzel for display and a system sans-serif for readable body copy. Oxblood #651f2b, warm white #f7f4ed, charcoal #292923, bronze #bda574. Broad photography, generous whitespace, hairline event separators; no application-style card grid. Home persuades; event and information pages serve reading. Navigation and date rows are consistent across routes. No animation required. Native details menu on mobile works without JavaScript.
